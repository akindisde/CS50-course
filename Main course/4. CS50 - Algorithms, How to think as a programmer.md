```c
#include <stdio.h>

int binarySearch(int arr[], int left, int right, int x) {
    while (left <= right) {
        int mid = left + (right - left) / 2; // Calculate middle index
        
        // Check if x is present at mid
        if (arr[mid] == x) {
            return mid;
        }
        
        // If x greater, ignore left half
        if (arr[mid] < x) {
            left = mid + 1;
        }
        // If x is smaller, ignore right half
        else {
            right = mid - 1;
        }
    }
    
    // If we reach here, then the element was not present
    return -1;
}

```

We jump now to **sorting**. 

Sorting has a lot of **criteria**'s chosen by the person who wanna sort the data, for example you can sort names **alphabetically**, or numbers **from smaller to greater**, and more.

Let's dive right into it with the **selection sort**, iterating through the data structure again and again positioning the *smallest number* each time.

The algorithm goes like this :

![[Pasted image 20240715114935.png]]

Here's the code for it :

```c
#include <stdio.h>

// Function to perform selection sort
void selectionSort(int arr[], int n) {
    int i, j;

    // One by one move boundary of unsorted subarray
    for (i = 0; i < n-1; i++) {
        // Find the minimum element in unsorted array starting from index i
        for (j = i+1; j < n; j++) {
            // Swap if the current element is smaller than the first element of unsorted array
            if (arr[j] < arr[i]) {
                // Swap arr[i] with arr[j]
                int temp = arr[j];
                arr[j] = arr[i];
                arr[i] = temp;
            }
        }
    }
}
```

Another solution is the **bubble sort**, where the great elements ***rise up to the end of the array*** like bubbles in the cola cup.

Here's the code for it : 

```c
#include <stdio.h>

// Function to perform bubble sort
void bubbleSort(int arr[], int n) {
    int i, j;
    for (i = 0; i < n-1; i++) {
        // Last i elements are already in place
        for (j = 0; j < n-i-1; j++) {
            // Swap if the current element is greater than the next element
            if (arr[j] > arr[j+1]) {
                // Swap arr[j] and arr[j+1]
                int temp = arr[j];
                arr[j] = arr[j+1];
                arr[j+1] = temp;
            }
        }
    }
}
```

The magic happens in the **merging** of the sorted halves.

Merge sort is a popular sorting algorithm that follows the **divide-and-conquer** paradigm. 

It works by dividing the array into two halves, sorting each half recursively, and then merging the sorted halves to produce a sorted array. Here's an explanation of how merge sort works in C:

28. **Divide**: Divide the array into two halves recursively until each sub-array contains only one element.
   
29. **Conquer**: Merge the divided subarrays back together in a sorted manner.

The merge function is central to merge sort. It takes two sorted sub-arrays and merges them into a single sorted array.

```c
// Merge Function
void merge(int arr[], int left, int mid, int right) {
    int i, j, k;
    int n1 = mid - left + 1;    // Size of left subarray
    int n2 = right - mid;       // Size of right subarray

    // Create temporary arrays
    int L[n1], R[n2];

    // Copy data to temporary arrays L[] and R[]
    for (i = 0; i < n1; i++)
        L[i] = arr[left + i];
    for (j = 0; j < n2; j++)
        R[j] = arr[mid + 1 + j];

    // Merge the temporary arrays back into arr[left..right]
    i = 0;   // Initial index of left subarray
    j = 0;   // Initial index of right subarray
    k = left; // Initial index of merged subarray

    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) {
            arr[k] = L[i];
            i++;
        } else {
            arr[k] = R[j];
            j++;
        }
        k++;
    }

    // Copy the remaining elements of L[], if any
    while (i < n1) {
        arr[k] = L[i];
        i++;
        k++;
    }

    // Copy the remaining elements of R[], if any
    while (j < n2) {
        arr[k] = R[j];
        j++;
        k++;
    }
}
```

The merge sort function recursively divides the array into halves, sorts them, and merges them using the `merge` function.

```c
// Merge Sort Function
void mergeSort(int arr[], int left, int right) {
    if (left < right) {
        // Find the middle point
        int mid = left + (right - left) / 2;

        // Recursively sort first and second halves
        mergeSort(arr, left, mid);
        mergeSort(arr, mid + 1, right);

        // Merge the sorted halves
        merge(arr, left, mid, right);
    }
}
```

Merge sort is efficient with a time complexity of **θ(n log n)** and is **stable** (preserves the relative order of equal elements). It is suitable for sorting large arrays and lists efficiently.
