One way to represent the data in the day-to-day basis is the **unary system**, counting from 0 to 9. 

This type of system is a **base-1** system utilizing just *one digit*. 

There are other systems out there, and computer use the **binary system** (base-2) as its way to represent and process data. 

We, humans, use the **decimal system** (base-10).

The binary system has two digits zero and one, represented in a **bit**, a short-term for **binary digit**. 

The question here is, how do computers solve hyper complicated problems using this very simple system to represent data ??

To answer that we need to know how does a computer represent the bit **physically** to begin with. 

Think of it as a light bulb 💡, when the bit is 0, it's off, when it's one, it's on.

That's all there is to it, only there are **millions of switches**(***transistors***) inside your computer ***going on and off*** electrically to represent/process huge amounts of data in a very short period of time.

You've guessed it by now, the bigger the data i wanna work with the more bits that i need. 

Let's count in binary now shall we :

![[slide_3-e1536284908144.jpg]]

  
We mentioned *base* often up there, but how do we actually see it the right way ? what does the base represent ?

Well if you wanna represent the number 1234 in the decimal base aka the base-10, you're gonna write this : 

```
1234 = 1000 * 1 + 100 * 2 + 10 * 3 + 1 * 4
```

which is in fact the same as this :

```
1234 = 10^3 * 1 + 10^2 * 2 + 10^1 * 3 + 10^0 * 4
```

Overall, our base is 10, and **as we go higher, the power we raise 10 by is going to grow higher** as well.

Since computers have electricity and nothing else to represent data, it uses base-2 to do this :

(1234)$_{10}$ = (1001 0010)$_{2}$ , so here 1234 as a human way of representing this number is just this 10010010 pattern of off and on switching inside the computer.

Numbers can get huge so we need a better unit to represent the space needed for them, introducing the **byte** as 8 bits.

So instead of saying this (1001 0010)$_{2}$ needs 8 bits in memory, we just measure it saying one byte.

Going even higher in memory size, there is *Kilo byte, Mega byte, Giga byte, Tera byte and more.*

Of course now you would think, well, that's it for numbers, but what about other data, text, audio, video, and more ??

It's just about other patterns of binary digits circulating around in different components in your computer under the hood!

Now let's take a look into how a computer represents colors on your screen, and furthermore, how can it display images and videos ?

Starting with colors, we introduce **RGB** (stands for ***Red, Green, and Blue***. It's a color model that is used to create a wide variety of colors by combining these three primary colors of light)

![[Pasted image 20240705142156.png]]

Meaning we can make different colors with specific amounts of red mixed with another amount of green and same for blue.

for example this is the RGB code for yellow is :

```
rgb(255, 255, 0) 
```

The **intensity** of red, green, and blue is represented from 0 to 255, stored in one byte for each.

So here, yellow is a mix of full intensity red and full intensity green, and no blue, just as if you were in an art class.

For a full picture to form on your screen, you need to know that your screen in any device is made with **pixels**, a lot of them. 

Each pixel is going to display a color, that color is represented by a certain combinations of zeros and ones. and full a full picture to be printed on the screen, millions of pixels form it with many colors.

And simple enough, videos are just sequences of images or **frames** been displayed at a certain speed. (meaning the pixels are changing colors so fast) and that's why media tend to be so big of size especially if it was of high definition.

It goes on and on, even when you change the nature of the data, although the processing parts is relatively complex, the idea is still the same; <u>a combination of zeros and ones being processed.</u>
